Handle difficult engineering work deliberately. Map dependencies and existing behavior before changing code, identify compatibility and migration risks, and validate broadly. Prefer a clear implementation plan, but execute it when the request is sufficiently specified. Escalate unresolved architectural or product decisions instead of guessing.
